# Living Market (Живой рынок) — Minecraft 1.20.1 Forge

Мод перерабатывает систему торговли с деревенскими жителями:

* **4 торга на каждый уровень:** ровно 2 сделки «Предмет → Изумруд» и 2 сделки «Изумруд → Предмет» (до 20 торгов на 5-м уровне).
* **Расширенный пул предметов в JSON:** мёд, соты, ядовитый картофель, осколки аметиста, светящиеся ягоды, медь, кальцит, туф, капельник, мембраны фантома, паутина, раковины наутилуса и др.
* **Ежедневная ротация + закрепление (до 2 торгов):** каждый новый день незакреплённые торги обновляются; до 2 сделок на жителя можно закрепить кнопкой над окном торговли.
* **Ручной реролл с ростом цены:** кнопка «Обновить» мгновенно меняет все незакреплённые торги (`1 → 2 → 4 → 8 → 16 → 32` изумрудов за день, сброс утром).

## Автосборка `.jar` на GitHub (без программ на ПК)

1. Создайте пустой репозиторий на [github.com](https://github.com) (кнопка **New**).
2. На странице нового репозитория нажмите ссылку **uploading an existing file**.
3. Распакуйте этот архив, зайдите внутрь, выделите все файлы и папки (включая `.github`) и перетащите в окно браузера.
4. Нажмите зелёную кнопку **Commit changes**.
5. Перейдите во вкладку **Actions** сверху, откройте сборку **Build Living Market Mod** и подождите ~2–3 минуты до зелёной галочки.
6. Внизу страницы в блоке **Artifacts** скачайте **LivingMarket-1.20.1-Forge** — внутри архива лежит готовый `.jar` для папки `mods`.
